## Block RAM 8×8

This project implements an **8×8 Block RAM (BRAM)** in Verilog HDL with an accompanying testbench for verification. The memory contains 8 locations, each storing 8-bit data. It supports synchronous read and write operations using a clock signal and includes an active-low asynchronous reset that clears all memory locations and the output. The testbench verifies correct functionality by writing data to different addresses and reading it back during simulation.
