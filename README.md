# Summer Internship 2026 , TKM College of Engineering

## About

This repository contains the design assignments, testbenches, and project work completed as part of a VLSI and Digital Design learning program using Verilog HDL and SystemVerilog. The designs were developed, simulated, and verified using AMD Vivado.

The repository covers fundamental digital circuits, sequential and combinational logic designs, protocol implementation, memory-based designs, and a CNN hardware accelerator project.

---

## Tools Used

* Verilog HDL
* SystemVerilog
* AMD Vivado 2023.2

### CNN Inference Accelerator

A SystemVerilog-based hardware implementation of a Convolutional Neural Network (CNN) inference pipeline consisting of modules for convolution, activation, pooling, flattening, and fully connected operations.
